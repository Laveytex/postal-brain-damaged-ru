# Русификатор POSTAL: Brain Damaged

Неофициальный фанатский перевод **POSTAL: Brain Damaged** на русский язык (Steam-версия, включая DLC «These Sunny Daze»).

Переведены все **1177** строк игры: меню и настройки, субтитры роликов, реплики Чувака, боссов и врагов, Кодекс, подсказки и обучение, названия уровней, оружия и предметов, титры. Подача — в духе русского Postal 2: чёрный юмор, разговорная речь, ругань ровно там, где она есть в оригинале.

Озвучка остаётся английской — переведены тексты и субтитры.

## Установка

1. Закрой игру.
2. Скачай `ru_patch_v1.0.zip` из [Releases](../../releases) и распакуй куда угодно.
3. Запусти `ru_patch.exe`, нажми **1** и Enter. Игра находится автоматически через Steam (или положи `ru_patch.exe` в папку игры). Установка занимает 3–5 минут.
4. В игре: **Settings → Language → «Русский»**.

Русский встаёт на место венгерского языка (в списке языков «Magyar» превратится в «Русский»), остальные языки не затрагиваются.

## Удаление

- `ru_patch.exe` → **2** — вернёт оригинальные файлы из резервной копии (`<папка игры>\_ru_backup`);
- или Steam: *Свойства → Установленные файлы → Проверить целостность файлов игры*.

## После обновления игры

Если Steam обновил игру, перевод может слететь — просто запусти `ru_patch.exe` снова. Патчер ищет тексты по их внутренним именам, а не по смещениям, поэтому переживает небольшие обновления.

## Частые вопросы

- **Антивирус ругается на exe.** Патчер собран PyInstaller'ом, на такие exe антивирусы иногда дают ложные срабатывания. Исходный код открыт — можно собрать exe самому (см. ниже) или запустить `ru_patch.py` через Python.
- **Вместо букв квадраты.** Не должно быть: патчер включает дополнительные страницы атласа у запасного шрифта игры. Если всё же увидишь — открой Issue со скриншотом.
- **Что не переведено:** встроенный туториал редактора модов (около 180 строк, хранятся отдельно).

## Как это устроено

Игра на Unity (IL2CPP, Addressables). Тексты — записи `LocalizedString` в `resources.assets`, `sharedassets0.assets` и бандлах `StreamingAssets\aa\StandaloneWindows64\defaultlocalgroup_*.bundle`. Патчер:

1. подставляет перевод из `ru.json` в слот `[HU]` каждой записи;
2. переименовывает язык «Magyar» в «Русский»;
3. включает мульти-атлас у динамического шрифта `LiberationSans SDF - Fallback` (его атлас 512×512 переполнялся, и часть кириллицы рисовалась квадратами);
4. отключает проверку CRC изменённых бандлов в `catalog.json`.

Файлы игры в репозитории и в релизе **не распространяются** — только перевод и патчер.

### Сборка и правка перевода

Нужен Python 3.12:

```
pip install UnityPy pyinstaller
build_exe.bat
```

Проверка перевода (теги `{0}`, `<color>`, `<input>`, `<br>` должны совпадать с оригиналом):

```
python tools/extract_loc.py "<папка игры>\POSTAL Brain Damaged_Data"
python tools/check_ru.py
```

Стиль и термины перевода — в [GLOSSARY.md](GLOSSARY.md). Правки и замечания — через Issues / Pull requests.

### English

Unofficial fan-made Russian translation for **POSTAL: Brain Damaged** (Steam, incl. *These Sunny Daze* DLC). Run `ru_patch.exe`, press 1, then pick **«Русский»** (replaces the Hungarian slot) in Settings → Language. Option 2 or Steam's *Verify integrity of game files* restores the originals. No game files are distributed.
